# 臺灣公共圖書館跨年統計：查重與可區隔新增值

查核日期：2026-10-25；產生時間：2026-10-25T15:20:33.532953+08:00。這是唯讀查重，不是完整資料匯入或授權法律意見。所有結論限於下列實際查閱範圍；搜尋未見不等於不存在。

## 判斷

官方已有機器可讀統計、跨年圖表、統計名詞與部分歷年長序列。單純把圖書館統計轉成 JSON、重畫跨年圖或重做名錄，重複程度很高。本輪未找到一個經實際查閱、同時具備「全臺多指標跨年觀測長表、逐年口徑映射、可再公開的原始來源版本／雜湊、可重現更新流程」的成熟替代品；這不是宣稱沒有這類專案。

**新增值應落在來源版本、口徑與可重現整理，且公開範圍受現行授權約束。** 2026-09-17 的[官方數據申請公告](https://publibstat.nlpi.edu.tw/Frontend/News/ShareNewsView?NewsID=News000050)說明：自民國 115 年起只公開部分全國年度總指標，其餘數據須申請；申請資料只限核准用途，不能擅自公開或轉供第三方。因此不能把舊開放目錄授權套用到新申請資料，也不能反過來逕稱舊已開放版本的授權被撤銷。應逐來源、逐版本建公開權利白名單。

## ahkimn/subwaybuilder-tw-maps 實際做了什麼

已讀取[專案](https://github.com/ahkimn/subwaybuilder-tw-maps) metadata、完整遞迴 Git 樹（`truncated:false`）、[README](https://github.com/ahkimn/subwaybuilder-tw-maps/blob/7c58f6c5fe72d61f64d1e8d1759797556251f8f4/README.md)及 [TPE 發行描述](https://github.com/ahkimn/subwaybuilder-tw-maps/blob/7c58f6c5fe72d61f64d1e8d1759797556251f8f4/releases/TPE.json)，核對提交為 `7c58f6c5fe72d61f64d1e8d1759797556251f8f4`，最後推送 2026-08-18，未封存。不是只看標題。

它是臺灣城市 Subway Builder 交通模擬地圖。README 說明從 0.2.0 加入圖書館旅次需求，將系統級流通量分配到分館，並因各館到訪計數基準不同而校正。這是應用端需求建模，不能把分配值當成每間圖書館政府原始觀測。README 引用 NCL，所列 `publibstat.ncl.edu.tw` 本輪未成功開啟；目前查到的 NCL 入口為 `libstat.ncl.edu.tw`，NLPI 公共館系統另為 `publibstat.nlpi.edu.tw`。尚不能因此判斷其取用來源不實，且 README 未明示圖書館統計原始年度。

查閱的公開 Git 樹主要是說明、圖片、部署設定與各城市發行 JSON，未見獨立圖書館原始長表、口徑字典或統計轉換程式；這只限該提交的公開樹，未下載 ZIP，不推論其私人流程或 ZIP 內部不存在。它已有地圖版本及 SHA-256，例如 TPE manifest 指向發行 ZIP、雜湊 `e9b0eb48ee8dc43f8b072ca3863ec7a43f1c2b7a020118535048719b7a34dd1e`。因此應說「沒有在已查樹中看到逐年圖書館原資料版本」，不能說它完全不可重現。GitHub metadata 判為 GPL-3.0，但地圖／程式授權不能替代上游政府資料權利。

本案可向這種應用提供可追溯、單位明確的原始觀測值，減少每位使用者自行釐清人次／冊數、觀測年度與館種的成本。

## 可區隔的交付與門檻

1. 只納入已確認可再公開的資料版本；保留原 URL、下載 URL、取得時間、雜湊、原始列／欄鍵與授權證據。未明權利與申請限用資料不進公開包。
2. 跨年長表保留原欄名、值、單位、統計期間、地域與館種；明列含國立館與排除學校館等範圍。到館人次、借閱人次、借閱冊數與模型推估分開。
3. 建逐年欄位映射及口徑變更紀錄，引用現有名詞定義章節；對不確定的對應保留未判定，不猜補。CNS 全文權利查明前不複製完整字典。
4. 交付可重現的更新與異動比對、完整性檢查及來源版本清單，AI 可取得觀測值與證據。若部分核心年份依法只能申請且不得再公開，公開成果需誠實縮小範圍及列缺口。
