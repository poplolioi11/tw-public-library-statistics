# 全臺公共圖書館統計：官方年份與統計口徑

查核日期：2026-10-25。已取得3份國圖年鑑公共圖書館章及3個主計總處歷史版本，實際擷取範圍詳見 `ncl-historical-verification.md`。本文的「確認」只限已列來源，沒有把現行定義反推成所有舊年相同。

最新補充：主計總處官方歷史全國表已取得並擷取，資料年最早可確認到1991年；目前4個核心指標可在不同版本間逐年查到1991–2011，第5個利用率可查到1993–2011。保留版本與原始口徑，沒有宣稱這些年度都有完整縣市或87欄。

## 母體、層級與重複計算

- 現行國資圖系統限**國內公立公共圖書館**；官方[系統簡介](https://publibstat.nlpi.edu.tw/Frontend/About/AboutpLibSTAT)明載「不含學校圖書館」。不能把國圖「全國圖書館統計系統」的所有館型直接合併。
- 官方[組合查詢](https://publibstat.nlpi.edu.tw/Frontend/Definition/DataCombinationSearch)有兩個不同空間維度：縣市別、層級別。後者選項含國立級、直轄市級、縣市級、鄉鎮市區級、直轄市山地原住民區立、其它；不是另一組可與縣市列相加的獨立母體。
- 官方[趨勢圖頁](https://publibstat.nlpi.edu.tw/Frontend/Dynamic/TrendChart)明文：「新北市、臺中市與南投縣含國立館資料。」
- 主代理取得的官方2023 JSON（`raw/probe-2023.json`）實際為26列：全國1列、22縣市列、以及新北／南投／臺中各一列「不含國立館」。後三列是同縣市替代口徑，**不得和原縣市列重複相加**，也不是三所國立館的獨立列。本檔未逐一核實15年是否都維持相同列集合。
- 「國家圖書館」與「國立級公共圖書館」不是可混用的分類。100年年鑑統計章頁255、258–259把國家圖書館、公共圖書館、大專校院、高中高職、國中、國小、專門圖書館分列；公共圖書館又可含公立與私立。提取時要保留館型。
- 2010年公共圖書館表確認使用合併前25縣市（臺中縣／市、臺南縣／市、高雄縣／市、臺北縣等）；需保留原地理名稱與原統計年，不能只改名就宣稱22縣市完全同口徑。正文表1、3、4均明列舊行政單位；表3註腳明確排除國立館並另列。

## 調查年、資料年與期間

[統計項目定義](https://publibstat.nlpi.edu.tw/Frontend/Definition/DefinitionItem)的填報說明：

- 資料期間是當年全年。
- 靜態資料以當年12月底事實為準；動態資料以當年1月至12月底事實為準。
- 與6425收集說明合併理解：資料年Y的全年營運數通常於Y+1年1–3月填報。資料年、實際填報／修正日、公開日、抓取日分開保存；不要按抓取日推算資料年。
- 「年度館藏增加量」是流量；「年底實有館藏量」是存量，不能把兩者混成同一個指標。

## 主要欄位的期間與含義

此表根據**現行**定義；跨年適用性尚未全部驗證。87個2023 JSON欄位的原名、分組、期間與查核程度另列 `definitions.json`。

| 項目 | 期間／單位 | 口徑與限制 |
|---|---|---|
| 圖書及非書資料收藏數量 | 12月底存量；原資料總量單位不應擅自統一成冊 | 現行定義包含圖書、非書、電子資源；分項有冊、種、張、片、捲、幅、件等異質單位，不能當每項都是冊。 |
| 館數、館舍面積、設備、編制人力、閱覽席位 | 依靜態一般規則，12月底 | 各細欄的單獨歷年填報手冊尚未查齊；不以當年出現過的人數當年底人數。志工人數的去重、累計或年底在冊細節未確認。 |
| 全年購買圖書資料費：預算／決算 | 年度財務量；元 | 分開保留，不互相替代。現行定義頁只明列每人購書費含圖書、非書及電子資源；各年經費細項與預算修正時點未確認。 |
| 全年圖書資訊借閱人次 | 全年流量；人次 | 一人一次借數冊仍算1人次，包含圖書與非書；電子資源排除。不是獨立人數或到館人次。 |
| 全年圖書資訊借閱冊數 | 全年流量；冊次 | 一人一次借數冊按冊數計，含圖書與非書，排除電子資源；不應和館藏冊數比較成同一種存量。 |
| 全年電子書借閱人次／冊數 | 全年流量；人次／冊次 | 現行定義寫「電子書」，而2023 JSON與目前報表有「年度電子書刊」；僅見名稱差異，尚未證實歷年電子期刊納入時點。 |
| 全年推廣活動場次／人次 | 全年流量；場次／參加人次 | 包含館方主辦與協辦；同一人可多次參與。類別與去重方式需按年核實。 |
| 每人擁書量、每人借閱量、借閱率等 | 衍生比率 | 官方提供文字定義，分母人口時點、四捨五入規則尚未核實；不直接把比率加總。借閱率按平均借閱人次，不是人口百分比。 |

## 已發現的歷年欄位風險

1. 現行組合查詢／人力結構有「約用(臨時)人員」「委外人員（承攬派駐人力）」及「行政輔助人員（工友技工及駕駛）」；2023 JSON使用「臨時人員」「編制內技術人員」，且未見獨立委外欄。**未確認何年變更、是否只是介面改名，不能直接視為等價。**來源：上述組合查詢、人力結構頁及官方2023 JSON。
2. 原JSON館藏區出現欄名「其他(決算)」，與預算決算區重複語意，但原值位於「一、圖書資料」的分項。保留原名、分組和位置，先標記疑似欄標問題，不自行更正成官方定義。
3. 東南亞圖書及非書資料量原欄已注明「包含於總館藏量下」；不能再加回總量。
4. 現行線上定義無標註發布日／歷史版號，不能證明2011年就採相同定義。2010年NCL表3的館藏包含非書與電子資源；主計表「藏書千冊」則與之不同，跨年跨機關必須對照原表，不能只按名稱合併。

- 2011以前各年公共圖書館章完整表、私立是否混入、國立館與其他館的分類差異。
