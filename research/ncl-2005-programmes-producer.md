## 原刊差異照存

表 6 推廣閱讀的 88 個原列人數由 Python 加總為 **16,454**，原表尾總計印 **16,374**，差 **-80**；總計格與 programme 總計列均有品質旗標，沒有改數字。示範觀摩 21 個原列人數加總 **5,431**，與原表尾相同。88 與 21 的表尾館數也與各自數值館別列數相符。

前頁正文另稱推廣閱讀參與 91 館，而表尾為 88 館。只在 metadata 記錄此差異，沒有用正文覆寫表格；正文不是本批新增的數量觀測。這些檢查證明擷取與來源一致，不代表官方填報內容必然正確。

## 方法、驗證與權利

原頁以 PDFium 核讀；中文多為輪廓，原生抽字不足，館名／欄頭／活動名與非數值狀態依原圖轉錄。數字按原欄界與 word 座標，由本機 Python／pdfplumber 擷取，每格做原 PDF word／去重字元一致性，並確認完整選區所有數值 token 恰好消耗一次。表 7 項次不是統計量，期間數字另作期間驗證，不混入 123 格數量。

已通過：全表及續頁對帳、119 programme IDs 與 123 observation IDs 唯一、123 格數字／原值 roundtrip、兩組 CSV／JSONL 每欄一致、完整來源 token 守恆、兩次離線重跑 bytes＋mtime 不變、缺來源與來源 SHA 改變兩種 fixture 都停止且保留舊輸出。這是 producer 自驗，未宣稱人類雙校；root 另安排來源先讀核查。

重播：

```sh
python3 scripts/extract_ncl_2005_programmes.py --offline --self-test
```

程式不發網路／AI 呼叫。原件版本改變時拒絕套用舊座標，先停下覆核。依賴僅 Python 3.12 標準庫、pdfplumber 及本支 script；PDFium／Pillow 僅用於原件影像核讀。

[NCL 開放宣告](https://www.ncl.edu.tw/open-government-declaration) 未確認署名年鑑章全文開放，本批只公開候選統計事實、必要短標籤與期間，不重製周邊大段署名正文、原圖或 PDF。沒有個人姓名、聯絡資料、公司評價或工程個案。來源全文／圖像持續私有。
