NCL可下載PDF保存在 `raw/ncl-historical/`，`documents.json` 記錄3份公共圖書館章節的官方網址、SHA256、大小、出版日與擷取範圍。DGBAS原PDF及 `dgbas-documents.json` 記錄另外3個版本與明確來源。國圖100年鑑的「各類型圖書館統計」另留為口徑研究參考，沒有把學校／私立館列匯入。

CSV與JSONL保留：`data_year`、`entity_raw`、`metric_id`、`metric_raw`、`value_raw`、`value`、`unit`、來源頁／附件URL、SHA256、本機原檔路徑、抓取時間、PDF實體頁、印刷頁、表號、資料列與欄。NCL `source_row` 是扣除表頭後的資料列；`source_column` 計入第1欄地理名稱，故人口欄是第2欄。DGBAS列是原表指標號序，欄是年度數值欄序（不計單位與指標名稱欄），`source_locator` 同時標西元年度。

## 如何重跑

本機已可使用的Python：

```sh
python scripts/fetch_ncl_historical.py --offline
python scripts/extract_dgbas_historical.py
```

在專案根目錄執行。前者需pypdf，後者需pdfplumber。前者可移除`--offline`重新取得缺少的官方原檔；有原檔時直接讀本機，避免重抓。後者從已保存的官方PDF做確定性座標擷取，遇到年份、儲存格格式或總格數不符即失敗，不猜補。

DGBAS下載使用正常TLS驗證。該站2026-10的伺服器漏送TWCA中繼憑證；本輪從伺服器憑證的AIA網址取得中繼憑證，以既有certifi根憑證執行`openssl verify -untrusted`，結果為OK，才在本次下載的暫存憑證組合內補鏈。沒有關閉TLS驗證、沒有更改系統信任庫；沒有繞過403，失敗的舊站入口改從搜尋已確認的官方`ws.dgbas.gov.tw`下載連結取得。此暫存下載環境不作為未來排程依賴；後續重新下載應先試正常TLS，必要時補齊同一可驗證鏈。

## DGBAS跨年表核對與定義

- [2005年官方PDF](https://ws.dgbas.gov.tw/public/data/331311404571.pdf)：PDF106–109頁／印刷122–125頁；指標16借閱人數、30館數、31每10萬人館數、32藏書千冊；1991–2005。PDF110頁／印刷126頁名詞解釋說每10萬人館數採年底公立公共圖書館數除以年底人口。該版2005數值尚未列出，以「…」呈現。
- [2008年官方PDF](https://ws.dgbas.gov.tw/001/Upload/466/ebook/ebook_88839/pdf/full.pdf)：PDF132–135頁／印刷124–127頁；指標17借閱千人次、18利用率、32館數、33每10萬人館數、34藏書千冊；1993–2008。PDF137頁／印刷129頁名詞解釋明定「圖書館利用率＝圖書借閱人次/年中人口*100」，不是獨立人口使用百分比；每10萬人館數的分子與分母都採年底。
- [2011年官方PDF章節](https://ws.dgbas.gov.tw/public/attachment/211231530971.pdf)：PDF1–4頁／印刷122–125頁；同樣5指標，1996–2011。以年度表頭定位各數字格，避免英文頁的單位「1,000 volumes」緊接末格數字而被誤併。
- 三版都只取「公立公共圖書館」指標，沒有把同PDF其他文化、學校、醫療等表匯入。
- 1998、1999年「臺灣省公共圖書館不含分館」為原註，逐列保留。
- 1999以前借閱人數定義為「閱覽人數」為中文原註；2011年英文註的敘述方向與中文不一致，保留矛盾，未自行調和或宣稱跨年完全可比。
- 「藏書千冊」與NCL年鑑「圖書及非書資料收藏數量」是不同指標，尤其後者包含非書與電子資源，不能自動接成一條線。不同版同年數值還可能反映修訂，均保留`source_edition`。
