## 年鑑與評鑑章

[103 卷官方目錄](https://www.ncl.edu.tw/librarianship-yearbook/0Q083565350919926814)明列出版日期 **2015-01-01**。本代理曾將卷號 103 換算的 2014 誤稱刊年，已撤回：`source_edition_roc=103` 是版次，不能當出版日期。這輪未另核版權頁，不改既有刊日。

103 卷《公共圖書館》PDF 2–7（印刷 72–77）核心表 31–40 均是 102＝2013 年資料。《圖書館統計》PDF 5（印刷 393）表 157 雖有 98–102＝2009–2013 年比較，只提供全國館數、館藏、閱覽席位、借閱人次及冊數，沒有縣市列。

[102 年全國公共圖書館評鑑工作紀要](https://www.ncl.edu.tw/files/file_pool/1/0Q083565357648017327/dc20b708-7092-4ae3-ac7e-ff8fe001c257.pdf)PDF 5（印刷 23）說評鑑對象排除國立公共圖書館，參考 101 年及 99–101 年營運數據；PDF 10（印刷 28）說後續統計混合公共館系統 101 年資料與部分初評報告。但表 14–28 刊的是不同館級、人口級距的達標／未達標／無資料館數。表 11 的 22 縣市列則是 2013 評鑑的受評及得獎館數。這些不能當成 2012 各縣市館藏、經費或借閱原始量，因此本輪不擷取。

[102 卷公共圖書館章入口](https://www.ncl.edu.tw/librarianship-yearbook/0Q083565374511489343)的 PDF 1–3（印刷 69–71）有 2012 全國、館級及部分縣市人均指標敘述；另一代理負責，這裡不重複匯入，也不以四捨五入人均值反推精確分子。

## 國資圖年報與主計總處

國資圖 [102 年年報原連結](https://www.nlpi.edu.tw/FileDownLoad/LibraryPublication/20160510094622367.pdf)仍被搜尋引擎索引，目次印刷 3 指向公共圖書館輔導 62、業務統計 134、附錄 142。然而精確 HTTPS 連結的 HEAD／GET 均回 HTTP 404；`FileDownload` 大小寫變體也 404；`w3.nlpi.edu.tw` 舊主機名稱解析失敗；HTTP 版逾時。舊出版品列表入口 GET 為 HTTP 400。本輪未取得整份 PDF，不以索引片段宣稱已讀全卷，也不判斷是否沒有完整 2012 縣市表。

[主計總處縣市重要統計指標目錄](https://winsta.dgbas.gov.tw/DgbasWeb/ZWeb/StateFile_ZWeb.aspx)已正常 HTTPS 取得完整 HTML，再對全部 `tr` 與 `a` 查「圖書館、借閱、館藏」。只有已收錄的 `Z091101a029` 公立公共圖書館個數，定義含國家圖書館、國立公共資訊圖書館及國立臺灣圖書館，沒有找到另一個借閱、館藏或人力系列入口。本結論只限本次現行目錄，不涵蓋所有歷史資料庫；未重複擷取館數。

[政府開放目錄 6425](https://data.gov.tw/dataset/6425)明示 OGDL 第 1 版，並說 2011–2017 年可到系統查詢。目前資源連結仍指向 `ConsolidationData?Year=2023`。舊年度可查不等於已取得 2012 完整下載包，也不把這項授權延伸至其他署名 PDF。
