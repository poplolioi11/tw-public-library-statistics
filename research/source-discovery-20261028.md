## 已完成的整表證據如何使用

[396個原格JSON](source-probes/20261028-original-cells.json)含臺南兩表240格、新北表6-2及續表156格，**不是抽幾筆數字**。每格有官方連結、PDF頁／表／列／欄／座標、原件SHA、原版識別、兩種PDF文字引擎保留的原字串與數值狀態。12格來源符號原樣保留為未知，不補0。

兩種文字引擎的396格數值／符號皆相符，並核讀所列原頁影像；這是擷取核對，不是兩個獨立官方統計來源，也不保證官方填報完全正確。所有原格都明列 `comparison_permission=none_probe_not_canonical_or_panel`。新北區列年份未明列、辦證單位未核，以及臺南跨年變動列均有獨立狀態。JSON中的`value`為十進位字串或null，避免工具自行把符號轉0。

此檔是來源研究層，不是新增正式觀測、不加入56,496筆既有量化層，也不送進現有折線圖。正式整批入庫還須補齊指標／母體／期間／單位分類、重複版本與定義規則，另出資料新版。

重跑時只讀指定官方原件，先鎖定SHA；不連線、不自動接受網站新版本：

```sh
python scripts/probe_library_source_tables.py --source-root /path/to/verified-originals
python scripts/validate_source_discovery.py
```

原件未附公開包。取得原件後，可加 `python scripts/validate_source_discovery.py --source-root /path/to/verified-originals` 核對全部16份原件雜湊並重跑396格；PDF重跑依既有requirements環境；本次XLS表內年份與註腳核讀使用xlrd 2.0.2。只看公開清單不需要下載原件或安裝解析套件。
