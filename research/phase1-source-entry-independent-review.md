## 需要保留的來源限定

- [彰化舊查詢入口](https://library.toread.bocach.gov.tw/)：HTTP200、437 bytes，title「Apache Tomcat」，為 JavaScript 轉向且 body 空白的殼頁。本輪沒有執行其 JavaScript，不把這個網址當統計頁。**原 inventory 已將此 check 標為 request_failed**，角色另有官方館首頁等支持來源，不能因此說整個角色或機關無資料。
- 新竹市主計處原列 114 年統計年報下載 URL：本次 HTTP200、宣告 application/pdf，但 body0 bytes，沒有 `%PDF`。原 check 也已是空 SHA 並標 request_failed；本輪確認此限制，沒有把它改為成功 PDF。完整原 URL 留在逐 check JSON，未另猜替代網址。
- 雲林文化主管、臺東開放資料、金門開放資料三角色本次未取得可用主題回應。雲林有存取挑戰，臺東原列網址為404，金門為連線失敗；皆不推論機關沒有資料。嘉義市兩角色只有列明支持頁部分可達，未用此覆寫主網址失敗。
- 其他 PDF 回應僅確認 bytes 與 `%PDF` 格式可取得；本輪未重新核 PDF 內的公共館表，也不從普通年報／統計目錄直接認證公共館完整序列。

## 指紋與驗收界線

本輪有91個去重原網址在可比較前版 SHA 的項目中出現不同 body 指紋（逐條 inventory check 比較共95條）。這包含動態頁面差異；**不視為統計值修訂**，沒有改資料表或矩陣。原 SHA 為前輪報告欄位；本輪才另保存完整 body 並做本機 bytes 重讀，兩種證據層次沒有混稱。
