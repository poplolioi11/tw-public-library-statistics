審查中發現的四項問題已交主代理修正，並加入相對應回歸測試：

1. **館舍面積級距被標為平方公尺**：已下載的 `Bacol00286` 原列以面積級距作為 `ItemName`，`legendName` 是「圖書館總面積(間數)」；數值為該級距的館舍間數。主程式已將標題改為「館舍面積級距分布（館舍間數）」、單位改為「間」，保留原級距字串與重疊邊界，不自行補正。
2. **事件日誌延後到整批結束才寫入**：若 manifest 已記新雜湊但程序中斷，重跑會視為未變而遺漏事件。主程式已改為每次新增／修訂先附加事件、flush、fsync，再保存 manifest。測試模擬 manifest 寫入完成後中斷，確認新版本事件已存在。
3. **全新目錄首次抓取缺少 data 目錄**：逐筆寫日誌後暴露此問題，主程式已於 acquisition 開始建立目錄。首次抓取及 A→B→A 測試涵蓋此路徑。
4. **HTTP 200 錯誤頁可能取代授權證據**：原先非資料頁僅檢查長度。主程式已對目錄、授權、定義、範圍、前端腳本、政策及年度選單增加內容識別；測試確認一般登入／拒絕存取頁不會被當成 data.gov.tw 6425 的授權頁。

修正後，這次測試範圍內沒有尚未處理的阻斷問題。

## 證據與解讀界線

- 公開圖表 JSON 本身沒有可用的資料年欄位；其 data_year 取自官方公開年度選項與送出的 Years 請求。API 的列首年分可以核對，不能宣稱公開圖表也有相同的回應內年分驗證。離線測試不證明上游在收到不同年度參數時一定回傳該年度真值。
- 原始 0 可以是實際零，也可能是上游未蒐集或系統補零；程式現在保留此不確定性。測試不把「成功解析 0」當成歷史欄位當年確實有蒐集的證明。
- 現行定義與年底／全年規則沒有被認定自 2011 年起完全相同；現有輸出保留 historical_applicability_unverified／not_certified 等狀態。測試只確認這些界線沒有在正規化時消失。
- 預算與決算、不同地理口徑、不同介面都需要由資料使用者明確選取。全國列不能再加縣市列，含與不含國立館替代列也不能相加。保留不同 series／scope 是追溯措施，不代表兩邊沒有重疊。
- 授權頁的內容識別是防止錯頁污染證據；本測試不另行認定所有年度、所有來源都有 OGDL。主程式仍只將明確連結的 2023 API 標為 OGDL，公開全國圖表另用統計事實來源狀態。
- 本報告沒有宣稱整套流程具備所有輸出檔案的交易式原子更新、停電後完全一次事件語意，或網路整批實際下載已完成。驗收的是上述明列的離線資料與故障情境。
