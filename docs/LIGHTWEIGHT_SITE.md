# 公開輕量圖表網站

固定入口：https://poplolioi11.github.io/tw-public-library-statistics/

曲宸宇（Chu, Chen-Yu）整理。閱覽器v1.1.0；統計資料v0.9.2。網站增加既有來源表的呈現，正式58,269筆原值、口徑及資料版本不變；固定v0.9.2 tag與附件保留原封存內容，網站更新以main commit識別。

首頁先載入manifest、一份問題目錄及一組數列；切換問題或數列才取所需JSON。JSON使用內容SHA命名，內容相同不重寫；瀏覽器同頁快取可重用已讀取分檔。無框架套件、外部字型、分析追蹤、登入、後端或全量JSON預載。沒有服務工作者，避免舊快取在新版繼續顯示。

全部1,677組原刊多期數列及2,767組問題內數列均轉出，847個區間直接複製原Python選源器的已核結果；重複出現在不同問題的數列不算新的觀測。未知點保留原紀錄且不畫成0；只連接原允許線段。明列的單期來源批次另外用完整表格呈現；其餘未解及不符繪圖條件的資料留在正式下載包。網站不是全部量化資料的替代格式。

每個圓點與表格數值連至官方原件；「原件與表位」列原始URL、SHA-256、頁／表／格位置、來源版本、原欄字串及口徑。部分官方查詢網址需要表單狀態，這時另連既有官方表目錄並明示須按表代碼、年度、地區重現；不冒稱可直接跳至單一格。原始URL及原件SHA仍不改。網站JSON的SHA只驗網站投影，不能用來驗政府原件。

手機版以原生文字標示座標刻度，固定至少12px；主要數值16px，輸入欄16px。窄螢幕顯示較少的同值X軸標籤，不刪點位；表格可在自己的容器內橫向捲動，整頁不應溢出。查詢條件保留在網址，可分享。資料下載失敗時清除舊圖並顯示重試，沒有合格區間時不換用其他來源。

## 2004年24筆單期來源表

固定入口：https://poplolioi11.github.io/tw-public-library-statistics/?batch=ncl94-statistics

國圖94年卷統計章表145、146、147的公共館子群，共16個原表格子、24筆正式觀測，分成16筆主量與8筆填答館數。表中只報2004年；本批沒有足夠證據新增跨年連線，全部用表格呈現。保留公立／私立、分館納入方式、填答母體及合作組織會員等不同角色，不將相近名稱混成一種館數。8筆原表未印單位仍為未知。

首頁有明顯來源表入口，也可在檢視種類選擇來源表。manifest僅放小型批次目錄，選取後才下載24筆JSON；切回圖表不改既有核准線段。每筆數值連官方原PDF的頁碼，詳情列原值、單位／期間狀態、頁表列欄、原件SHA與來源版本。與正式觀測逐筆比對，未轉換單位、補值或把單期記錄接成年序列。

**人工抽樣核讀0/120，人工雙校尚未完成。** 網站首頁及批次上方都顯示；程式核對、AI原圖讀回及這次網站驗收不算人工完成。正式資料包與原表說明見[94年卷完整子群](NCL94_STATISTICS.md)。

## 重建與驗證

使用Python標準函式庫，既有來源包即可重建，不會連網抓資料：

```sh
python scripts/light_site_update.py
python scripts/validate_lightweight_site.py
```

建置輸入為既有phase2/phase3可攜閱覽頁、逐筆口徑、正式觀測（含明列來源表24筆）及前端三檔。驗證器獨立比較全部原點值、缺值、原位置、原單位、口徑、來源、線段及區間選源；初次載入的未壓縮檔案總量上限1MiB。輸入雜湊相同且輸出完整時不重建；失敗還原前版。更新器在既有來源更新流程最後執行，沿用每月維護頻率，不另建網站抓取排程。

另可用已安裝的Node.js與Playwright執行隔離無頭瀏覽器測試；不連使用者瀏覽器：

```sh
node scripts/test_lightweight_browser.cjs
```

測試320/375/390/768/1440px、預設圖表初次只有三個JSON請求，批次深連結只載manifest與一份來源表JSON，並核對24筆全量及批次文字字級、刻度字級、逐筆來源、精確區間、拒用區間、缺漏期間、月資料缺期、動態官方查詢提示及載入失敗重試。`--url`可指定正式公開網址進行同一組回讀。

GitHub Pages只部署`site/light/`，須先通過同一commit的公開包CI。既有完整單檔閱覽頁與正式CSV／JSONL／SQLite仍在儲存庫及原Release。免費專案網址由GitHub提供，不需要購買網域；沒有改動yigua.art或其DNS、部署與資源。
