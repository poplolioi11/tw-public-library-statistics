# v0.9.1：年度、單位與來源定位覆核

本輪逐組回查v0.9.0全部467筆參考年度缺值、16,286筆單位缺值；主資料仍58,245筆，沒有新增觀測，也沒有改動數字、原字串、缺值、識別碼、來源鍵或期間。

- 91年卷來源摘要補列PDF第5頁、印頁75。表13續頁的9格原本已在資料中，逐筆來源不變。
- 14,584筆地方JSON按原欄名「冊數／人次」確認單位；冊、人次各7,292筆。保留unit_raw原null，以unit_basis與source_unit_context_locator指出明示單位的原欄名。
- 國圖103–114年鑑12筆同年全國電子資源合計，依同卷正文明印的「種」確認。僅限這12格；56個其他層級電子小計及混合總館藏不外推。
- 單位仍未知1,690筆，逐筆列原欄名、原件SHA/URL/定位及保留原因。包含空白單位、未印幣別、混合媒體、原文衝突及未明示計數方式。
- 年度467筆全部保留null：彰化11、臺南8是跨年變動；主計192、新北116、桃園140沒有足夠的逐列年份證據。出版年、「以某年為主」、相鄰列及數值不能代替原表明示。

**人工雙校未完成。**本輪是程式及AI回查原件，沒有新增真人獨立讀值，也不報全庫準確率。2012年22縣市核心原量仍缺；不推算、不跨來源拼接。已知年度但時點/流量口徑未確認的其他紀錄仍按原標記，不因這輪年度缺值覆核而認證。
